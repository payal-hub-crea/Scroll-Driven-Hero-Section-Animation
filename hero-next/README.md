# Scroll-driven hero (Next.js + Tailwind + GSAP)

## How to run (sorry but for my understanding I added marathi comment)
    npm install
    npm run dev      # open in browser  http://localhost:3000

## Files
- components/Hero.jsx   -> main work: layout + load animation + scroll animation (comments madhe sagla samjavla ahe)
- components/CarSvg.jsx -> car  drawing (SVG)
- app/page.js           -> main page
- app/layout.js         -> fonts and page title
- app/globals.css       -> Tailwind + car cha size
- tailwind.config.js    -> colours and fonts
- postcss.config.js     -> Tailwind sathi setting
- package.json          -> required  libraries (next, react, gsap, tailwind)
- hero-scroll.html      -> same design plain HTML + CSS + JS + GSAP version
